## Data Availability and Sources

The repository includes spatial data subsets and summary tables used in the project.

- **NAT2 (2018):** Historical forest conservation prioritization raster from the Finnish Environment Institute (Syke), clipped to the study areas. Licensed under CC BY 4.0.
- **Natura 2000:** Protected area data from Syke, clipped to the study areas. Licensed under CC BY 4.0.
- **GBIF:** Mammal occurrence data from 2016–2025. Summary tables are provided; the original data should be obtained from GBIF, with appropriate attribution to the contributing datasets.

The spatial subsets were prepared for this project and do not represent updated versions of the original datasets.

**Original data sources:**
- [Syke — Natura 2000 and downloadable spatial datasets](https://www.syke.fi/en/environmental-data/downloadable-spatial-datasets)
- [Syke — High Biodiversity Value Forests 2018 (Zonation)](https://luontotieto.syke.fi/en/aineisto/monimuotoisuudelle-tarkeat-metsaalueet-high-biodiversity-value-forests-2018-zonation-fin-eng-swe-2/)
- [GBIF — Biodiversity occurrence data](https://www.gbif.org/)
